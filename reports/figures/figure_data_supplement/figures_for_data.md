Final figures in main text and supplement. Numbers used here are final, whereas in file names they may be out of date. If "Manually composed" images are assembled of figures listed. If a panel is provided only the data underlying the panel is required. Where a figure contains multiple panels and none are noted, include all seperately.

These data are to satisfy the following requirements for peer review submission:
"For relevant manuscripts, we may request a source data file in Microsoft Excel format or a zipped folder. The source data file should, as a minimum, contain the numerical data underlying any graphs and charts, and uncropped versions of any gels or blots presented in the figures. Within the source data file, each figure or table (in the main manuscript and in the Supplementary Information) containing relevant data should be represented by a single sheet in an Excel document, or a single .txt file or other file type in a zipped folder. Blot and gel images should be pasted in and labelled with the relevant panel and identifying information such as the antibody used. We also encourage authors to include any other types of raw data that may be appropriate. An example source data file is available demonstrating the correct format."

Example file format: "reports/figures/figure_data_supplement/ncomms-example-source-data.xlsx"
