# s02 — Cross-platform reproducibility (this campaign vs GDPa1)

Quantifies how well per-antibody developability summaries from this campaign
agree with the published GDPa1 measurements for the same molecules. Sets the
expectation for what "good agreement" looks like before we make claims about
N3 ↔ N4 relationships.

The mapping from this campaign's `(value_col, condition)` to a GDPa1 column
is encoded in `prophet_ab.schema.PROPHET_TO_GDPA1`.

See `manifest.yaml` for inputs and outputs.
